This folder should contain `background.png` used by `password_checker_gui.py`.

The GUI will try to load `assets/background.png`. If you have the generated HUD image, copy it here.

If you don't have an image, you can generate one with:

    python ..\scripts\generate_hud.py

(From this folder run: `python scripts\generate_hud.py`)

If you prefer not to include the image in the upload, leave this folder empty.
